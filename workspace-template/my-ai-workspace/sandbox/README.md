# Sandbox: safe sample data

Everything in here is fictional: **Northside Plumbing & Gas**, a 24-person plumbing and gas business in Melbourne's north. Use it to try any workflow without touching real customer information.

| File | Try it with |
|---|---|
| `sample-meeting.md` | `/meeting-to-actions sandbox/sample-meeting.md` |
| `sample-emails.md` | `/email-reply-drafter sandbox/sample-emails.md` |
| `sample-enquiries.md` | `/enquiry-triage sandbox/sample-enquiries.md` |
| `sample-brief.md`, `sample-brief-excluded.md` | `/proposal-drafter sandbox/sample-brief.md` |
| `sample-reviews.md` | `/review-responder sandbox/sample-reviews.md` |
| `sample-invoices.csv` | `/invoice-follow-up sandbox/sample-invoices.csv` |
| `sample-process-notes.md` | `/sop-writer sandbox/sample-process-notes.md` |
| `sample-calendar.md` (with `sample-emails.md`) | `/weekly-business-brief` |
| `sample-post-ideas.md` | `/social-post-writer` with one of the ideas |
| `sample-role-notes.md` | `/job-ad-writer sandbox/sample-role-notes.md` |

`example-business-dna/` is a filled-in Business DNA for Northside. Copy the five files into `business-dna/` to see how much better the outputs get once the AI knows the business. Copy your own back afterwards.

Some samples are deliberately tricky (a refund the rules don't allow, a review that names a staff member). See whether the workflow handles them the way you'd want.
